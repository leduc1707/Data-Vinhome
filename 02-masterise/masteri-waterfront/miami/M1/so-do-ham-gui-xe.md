# Sơ đồ hầm gửi xe — M1 (Miami)

Chưa có bản đồ hầm hoặc thông báo vận hành đủ căn cứ cho tòa M1. Không suy số tầng hầm, hầm liên thông, trạm sạc hay lối xe từ các tòa lân cận.

| Dữ liệu cần thu | Giá trị / file chứng cứ | Nguồn cần có |
|---|---|---|
| Số tầng hầm, tên tầng | | Bản vẽ / bảng niêm yết |
| Phạm vi hầm dùng chung | | Sơ đồ ghi rõ tòa/khu vực |
| Cửa vào / ra phục vụ M1 | | Tên đường, biển cửa hầm và ảnh |
| Chiều di chuyển / ram dốc | | Sơ đồ phân luồng hiện hành |
| Khu ô tô, xe máy, xe đạp | | Mã khu, mã cột, biển chỉ dẫn |
| Lối đi bộ tới sảnh thang M1 | | Sơ đồ có ký hiệu tòa |
| Vị trí sạc và loại xe được sạc | | Thông báo đơn vị vận hành; không mặc định có trạm |
| Phí xe, phí sạc và điều kiện đăng ký | | Biểu phí có ngày hiệu lực và VAT |
| Tốc độ, giờ ra vào, quy định an toàn | | Nội quy niêm yết tại hầm |
| Gửi xe ngoài hầm / buggy nếu áp dụng | | Điểm đón, lịch chạy, đầu mối và phạm vi phục vụ |

## Nguồn

- Sơ đồ và biểu phí được BQL xác nhận cho M1: chưa thu thập tại ngày 30/09/2026.
- Thông số giới thiệu dự án không thay thế sơ đồ hầm thực tế. Phí và giờ buggy ở bản cũ chưa được đưa vào dữ liệu đã xác minh.
