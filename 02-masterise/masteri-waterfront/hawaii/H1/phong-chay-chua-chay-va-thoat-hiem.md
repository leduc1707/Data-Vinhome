# Phòng cháy chữa cháy và thoát hiểm — H1 (Hawaii)

Chưa thu được sơ đồ thoát nạn và phương án PCCC riêng tòa H1. File này là danh mục dữ liệu cần thu, chưa phải hướng dẫn thoát nạn. Không lấy sơ đồ của tòa khác thay thế.

| Dữ liệu cần thu | Giá trị / file chứng cứ | Yêu cầu đối chiếu |
|---|---|---|
| Sơ đồ tầng hầm và lối ra ngoài | | Đúng tòa/khu vực, có vị trí đang đứng |
| Sơ đồ tầng sảnh | | Cửa thoát ra ngoài và tuyến tiếp cận |
| Sơ đồ các loại tầng căn hộ | | Phạm vi tầng áp dụng, mã buồng thang |
| Sơ đồ tầng tiện ích / tầng mái | | Công năng thực tế và đường thoát |
| Tầng lánh nạn, nếu có | | Hồ sơ hoặc biển chỉ dẫn xác nhận |
| Điểm tập kết chính thức | | Bản đồ và thông báo BQL |
| Số lượng / vị trí buồng thang thoát nạn | | Bản vẽ hoặc sơ đồ niêm yết |
| Vị trí thiết bị báo cháy, chữa cháy | | Sơ đồ và ảnh niêm yết |
| Lối tiếp cận / họng tiếp nước chữa cháy | | Bản vẽ được xác nhận |
| Đầu mối trực sự cố | | [Danh bạ riêng H1](so-dien-thoai-truc-toa.md) |

## Nguồn và cách lưu

- Chưa có bản sơ đồ, hồ sơ nghiệm thu hoặc phương án của H1 trong kho tại ngày 30/09/2026.
- Khi thu thập, ghi đơn vị ban hành, tên/mã bản vẽ, ngày/phiên bản, tòa và tầng áp dụng; ảnh phải đọc được nội dung chỉ dẫn.
- Số tầng công bố trong [thông tin tòa](THONG-TIN-TOA.md) không chứng minh vị trí lối thoát hoặc tầng lánh nạn.
